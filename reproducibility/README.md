# Reproducibility information

* `../environment.yml` is the **portable** dependency specification (direct dependencies, unpinned).
* `environment_snapshot_macos-arm64.txt` is a **machine-specific snapshot** of the conda environment the saved
  results were produced with (macOS arm64, Python 3.11, RDKit 2026.03.1, Vina 1.2.7, Meeko 0.8.0, PoseBusters 0.6.5,
  scikit-learn 1.9.1, NumPy 2.4.6, pandas 3.0.6). It records what was used; it was not generated by reinstalling
  anything and is not guaranteed to resolve on another platform.
* Each GA run written after the repair pass has a `<output>.manifest.json` with its effective settings, package
  versions, platform and git commit. Each new docking run directory has a `manifest.json` with the receptor hash, box,
  Vina settings, ligand-preparation seed and versions. The historical result files have neither: they predate the
  manifests and no provenance is reconstructed for them.
* Tests: `python -m unittest discover tests` (standard library only).
