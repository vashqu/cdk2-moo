# Claim-to-evidence table

Each row points at saved tables; numbers are in those tables (or in `README.md`), not repeated here. Tables are under `campaigns/c2026-10-03/<policy>/results/` (`shared/results/` for policy-independent ones). I read the rows and checked the quoted values against them in the cleanup; I computed nothing new.
**Counting default** ("population rows"): rows of the saved population files for generated molecules (born after generation 0) in the stated generation, raw stored SMILES, every occurrence, one value per GA run (n = 5 runs, seeds 42-46). Exceptions are stated.
"Transfer" is always named by what is measured: surrogate prediction, fingerprint proximity, docking score; measured activity of generated molecules does not exist.
